# 提示词知识库设计

状态：具体设计草案，尚未进入产品代码实现。用户已给出导航位置、ChatGPT 参考、复制需求与图片可暂定的要求；来源范围问题已发出，当前提案按“精选画廊＋我的视觉记忆，仅本人可见”处理。

## 想解决的事

让用户从一张有吸引力的风格卡片找到可直接复用的完整提示词。右上角新增“提示词”，复用首页、设置、用户名的 PillNav 外观和悬停动效。打开后是独立、铺满内容区域的提示词页面，保留导航和返回聊天能力，不破坏当前对话、附件、正在执行的任务。使用覆盖内容区的独立全屏浏览层；底下原聊天组件保留挂载并隐藏，返回时连未发送文字/已选择文件也保持，不通过切换 page 条件分支重建 ChatArea。直接访问 #prompts 时底层按正常登录/会话恢复初始化，关闭后回到聊天或原首页。

## 页面与交互

- 顶部：bobo 标识、页面标题“提示词”，右侧仍是同款胶囊导航；聊天入口及首页均可到达，地址可用 #prompts 刷新恢复。
- 主区采用白灰画布，图片卡片为视觉主体，随屏幕显示 4/3/2/1 列；不同高宽比形成有节奏的图库布局，使用卡片底部渐隐标题而非后台表格。
- 内容切换为“精选画廊”“我的视觉记忆”；分类中文化、提供“全部”及分类筛选，搜索支持标题/正文/标签/分类的宽松关键词匹配。第一版不假造热度排名或使用量。
- 每次呈现 24 张卡片，显式“加载更多”，搜索/切换来源或分类后回到首批；空结果可清空筛选，网络错误可重试。
- 卡片点击打开详情：桌面左侧大图、右侧标题/来源/完整可滚动提示词，底部固定“复制提示词”；手机改为上下排列。详情保留分类、已声明尺寸/质量/标签与出处；未声明值不编造。
- 复制必须复制完整原文，保留换行/JSON/符号，不复制摘要、标题或图片链接；仅成功后显示“已复制”。剪贴板拒绝时展示可选中全文，供手动复制。
- 关闭按钮、背景点击及 Esc 可关闭；弹层焦点约束并回到原卡片，支持键盘、可见焦点和减少动态效果。恢复聊天时保留当前会话状态，不自动发送提示词。

## 视觉语言（执行者的设计选择）

继承项目现有颜色：画布 #f6f6f7、表面 #ffffff、主文字 #17171a、辅助文字 #57575e、细线 #ececee。沿用现有中文无衬线字体与字号体系，标题 30～36px，卡片标题 15～16px，提示词正文 14～15px。仅图片/封面有色彩，操作与导航延续黑白。圆角区分卡片 18px、详情 24px、导航胶囊；不用大幅装饰渐变或新字体库。暗色模式使用现有变量。

## 数据来源与运行方式

### 精选画廊

复用已有 CommonMark 解析器和固定来源仓库 9f8aa1a44a4a5c0f5a5d6e45eed564b3e2d5b87f，导出完整 164 段提示词、31 分类为有版本的静态 catalog，随前端懒加载。正文、稳定 ID、分类、作者/出处、尺寸/质量/标签等来自实际 Document，不靠手写少量假模板冒充完整库。保留 MIT 许可及第三方来源标记。该浏览能力不依赖当前关闭的付费向量检索/导入功能，不调用 EmbeddingModel 或 ChatModel。

首版使用轻量本地风格示意封面并标明；后续通过稳定 ID 的封面映射及图片目录替换，文档说明具体改动位置。拒绝不安全 URL scheme，缺失/加载失败自动回退封面。已有上游图片链接只保留出处，不在用户打开页面时请求未知外站。

### 我的视觉记忆

现有 vision_memory 保存用户的场景分析和指令，不是公共精选提示词。新增只读、鉴权、租户与用户双过滤的浏览接口，在当前 active 记忆中提供可复用描述，标注“来自我的视觉记忆”，不宣称为图库原作或模型质量评审。原始 structured_json 的主体、配色、构图、情绪可用于展示；提示词正文来自实际记忆内容，保留其创作要求。没有可用记忆时展示真实空状态和返回聊天入口，不填入虚构个人记忆。

只读浏览不触发 embedding/reindex/生成、不扣 Token；后端限每页 24、按 updated_at/id 稳定分页，限制搜索长度，参数化 SQL。沿用 /api/settings/visual-memory 的 chat:use 权限与 owner resolver。账号切换、退出和组件卸载中止在途请求、清空私人内容；旧响应不能落入新账号。私人内容不落公共静态文件。

## 具体范围与保留

- 复用 React/TypeScript、现有 PillNav/主题/提示组件；不引入新的 UI 框架或图片收费服务。
- 不启用尚未验收的画廊向量导入，不增加自动付费模型调用，不做社交公开个人记忆、点赞排行榜、收藏同步或自动生图。
- 不覆盖正在编辑的 src/index.css、src/main.tsx、src/theme.css；新页面样式独立且受容器 class 约束。干净快照从已验证提交创建，整合时只提交本功能的文件。
- 验收包括完整目录/原文复制、搜索与分页、移动端/暗色、弹层焦点、剪贴板拒绝、记忆空状态/账户切换/越权、浏览零模型调用及聊天状态保留。运行必要后端测试、前端现有脚本和真实 Chromium，并检查截图。
- 沿用本项目既有交付流程：完成实现、测试和 README 说明，提交两个工作分支，并在保留回滚版本后部署 boboo.xin；上线核对公网构建与只读 API。若用户选择只用公共模板，则删去个人记忆接口与对应 tab，其余不变。
